This is a module for v13 of Foundry Virtual Tabletop. It's api documentation can be found here: https://foundryvtt.com/api/

It uses PIXI.js version 7 to display background, tokens and tiles for remote playing of tabletop roleplaying games. It's api documentation can be found here: https://pixijs.download/v7.x/docs/index.html

Use source files under `./foundry` to understand the client side javascript for this web application.
